# 곁 음성 구체

v0.5.0부터 일반 앱은 무채색 입자 구체와 우측 상단 **설정** 버튼만 표시합니다. 속도계·이벤트 카드·주행 시작/종료·캐릭터 선택 버튼은 메인 화면에서 제거했습니다. 웹 가상주행의 도로·차량 조건이 달라지면 기존 코칭 엔진과 음성 파일을 그대로 사용합니다.

앱 실행 시 저장된 입력 모드로 서비스를 시작합니다. 웹 모드에서는 입력을 기다리며 구체가 천천히 움직입니다. 주행 음성이 실제 재생될 때 구체의 반경·입자 위치·밝기와 중심 빛이 음성의 강약에 반응하고, 음성이 끝나거나 중단되면 조용한 움직임으로 돌아갑니다.

## 백그라운드 사용

v0.5.1부터 구체 화면에서 뒤로 가기를 누르면 구체 화면만 닫습니다. Pleos 분할 화면에서 작업을 뒤로 보내도 화면이 남는 동작을 피하며, 홈으로 이동하거나 다른 내비게이션 앱을 열어도 foreground service가 센서 확인·판정·기록·음성 안내를 계속 처리합니다. 최근 앱에서 화면을 제거해도 서비스는 작업과 함께 종료되지 않도록 명시했습니다. 알림의 **주행 종료**가 명시적인 중지 방법이며, 알림을 누르면 구체 화면으로 돌아옵니다.

웹 시험에서는 에뮬레이터와 8090 웹 탭을 켜두어야 가상 센서가 들어옵니다. 앱 화면을 내리는 것과 웹 탭을 닫는 것은 다릅니다. 웹 입력이 끊기면 기존대로 음성을 중지하고 연결을 기다립니다. Android의 앱 강제 종료·활성 앱 중지나 기기 종료 후까지 계속 동작하는 것은 아닙니다.

**설정**은 정차 중 열 수 있습니다. 네 목소리 선택, 음성 안내 켜기/끄기, 선택한 목소리 미리 듣기만 제공합니다. 선택은 현재 운전자에 바로 저장되며 화면을 닫거나 앱을 다시 열어도 유지됩니다. 등록한 개인 녹음의 우선순위와 기존 데이터는 유지합니다. 운전자/녹음 등록/진단용 기존 MainActivity는 일반 화면과 분리했습니다.

## 음성에 맞추는 방법

Media3의 `ForwardingAudioSink`에서 디코딩된 PCM을 읽고 20ms 구간별 RMS를 계산합니다. 디코더는 소리보다 미리 처리할 수 있으므로, 도착 시점이 아니라 **오디오 출력의 현재 재생 시각**으로 해당 구간의 값을 선택합니다. 원래 오디오 버퍼는 수정하지 않습니다. 마이크·시스템 소리 녹음·RECORD_AUDIO 권한을 사용하지 않으며, 임의 파형이나 상황 ID별 애니메이션을 재생하지 않습니다.

PCM pre-roll에서는 반응을 억제하며 실제 음성 트랙이 재생될 때만 진폭을 구체에 전달합니다. 음성 종료·오류·오디오 포커스 상실·음소거·웹 입력 중단 시 진폭은 0이 됩니다. 일반 회전은 Compose의 무한 전환, 음성 반응은 짧은 스프링 보간으로 부드럽게 표시합니다.

참고한 고정 버전 API: [Media3 1.4.1 ForwardingAudioSink](https://github.com/androidx/media/blob/1.4.1/libraries/exoplayer/src/main/java/androidx/media3/exoplayer/audio/ForwardingAudioSink.java).

## 실행

`웹 가상주행 시작.command`를 실행하고 [8090 웹 가상주행](http://127.0.0.1:8090/)에서 출발합니다. 앱에는 구체가 표시되며 웹의 ACCEL/BRAKE·벨트·창문 등으로 조건을 변경합니다. 설정에서 목소리를 선택한 뒤 뒤로 돌아오면, 이후 코칭도 선택한 목소리와 구체 반응으로 이어집니다. 웹과 에뮬레이터는 모두 켜두세요.
