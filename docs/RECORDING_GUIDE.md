# 녹음 상황 안내

좋은 상황 25개·주의 상황 25개·공통 8개입니다. 네 캐릭터 모두 녹음하면 상황 200개와 공통 32개로 총 232개 슬롯입니다. 일부 상황만 먼저 교체해도 됩니다.

조용한 장소에서 멘트 하나당 파일 하나로 녹음합니다. 권장 길이는 2–8초, 허용 범위는 0.5–30초·10 MB 이하입니다. WAV 또는 MP3를 권장합니다. 캐릭터의 말투로 바꿔 읽어도 상황의 의미는 유지해 주세요.

폴더 이름은 friend / grandma / mom / sibling입니다. 예: friend/G01.wav, mom/B02.mp3. 앱의 목소리·녹음에서 등록하거나 개발자가 import_recordings.py로 APK에 포함합니다. 제공받은 사람 녹음은 임시 합성 음성보다 먼저 재생됩니다.
