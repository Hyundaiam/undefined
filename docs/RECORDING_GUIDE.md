# 녹음 상황 안내

좋은 상황 15개, 주의 상황 15개와 공통 멘트 8개입니다. 아래 문장은 의미를 전달하는 예시이며 각 캐릭터 말투로 바꿔 읽어도 됩니다. 상황 ID와 뜻은 유지해 주세요.

녹음은 주행 중이 아닌 조용한 장소에서 진행합니다. 파일 하나에는 멘트 하나를 넣습니다. 권장 길이는 2–8초이고 파일 앞뒤의 긴 무음, 배경 음악, 과도한 효과를 빼 주세요. WAV 또는 MP3를 권장합니다.

네 캐릭터 폴더는 `friend`, `grandma`, `mom`, `sibling`입니다. 예: `friend/G01.wav`, `grandma/B01.mp3`. 네 가지 모두 녹음하면 기본 120개, 공통 32개로 총 152개입니다. 일부만 먼저 전달해도 해당 파일만 교체할 수 있습니다.

## 기능과 녹음의 관계

이 목록은 녹음·시연용 상황 목록입니다. 30개 상황 모두가 현재 공개 SDK만으로 자동 감지되는 것은 아닙니다. 실제 센서가 없거나 지원되지 않으면 해당 상황은 자동 판정하지 않습니다. 시연 입력은 실제 운전자 학습 데이터와 분리합니다. 급제동이 불가피했던 상황은 나쁜 습관으로 감점하지 않습니다. 좌석 각도는 제조사/좌석별 지원 범위와 정차 중 설정한 기준을 사용하며 숫자 하나를 모든 차량에 적용하지 않습니다.

현재 기존 음성은 정확히 대응되는 상황과 인사·격려 멘트에만 임시 연결되어 있습니다. 대응 파일이 없는 상황은 녹음 대기로 표시하며 다른 상황의 멘트를 잘못 재생하지 않습니다. 제공해 주신 녹음 파일은 임시 파일보다 우선합니다.
