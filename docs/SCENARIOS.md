# 상황 50개 · 재현과 음성 안내

좋은 상황 25개와 주의 상황 25개를 각각 별도 규칙과 음성 파일에 연결했습니다. Gleo AI 자동 판단이 아닌 요청에 따른 하드코딩 대안입니다.

## 테스트 방법

1. 공식 차량 콘솔의 차량을 0 km/h · P단으로 둡니다.
2. 프로젝트의 **50상황 음성 테스트.command**를 더블클릭합니다.
3. 곁 앱에서 캐릭터와 좋은/주의 분류를 고르고 상황을 선택합니다.
4. **센서 상황 재현**을 누릅니다. 합성 센서 시퀀스가 규칙 엔진에 들어가고, 감지된 ID와 같은 음성이 나옵니다.
5. 선택만 바꾸면 음성은 나오지 않습니다. 오른쪽에서 감지 결과와 음성 안내 중/완료를 확인합니다.

최대 31초 분량의 시험 입력을 약 5초로 빠르게 재현합니다. 실제 차량 입력은 이 시뮬레이터와 섞지 않고 DEMO 출처로 저장합니다. 현재 SDK로 들어오지 않는 보행자·차선·실내 손/발 등의 정보는 이 시험에서만 명시적으로 공급합니다.

- 욕쟁이 할머니: 거리 넉넉히 두고 가니 잘했다.
- 걱정 많은 엄마: 앞차와 거리 잘 두고 있어서 안심돼.
- 5살 동생: 앞차랑 멀찍이 가네! 편안하다!
