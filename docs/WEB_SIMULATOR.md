# 웹 가상주행

브라우저에서 차량을 운전하고 도로·주변·실내 상태를 바꾸면, 에뮬레이터의 곁 앱이 조건을 계속 판단해 기존 캐릭터 음성으로 안내합니다. 웹은 정답이나 상황 ID를 보내지 않습니다. 50상황의 규칙과 음성은 유지하되 시험 버튼을 눌러 결과를 재생하는 흐름에서 연속 주행으로 바꿨습니다.

## 실행

Mac에서 프로젝트의 **웹 가상주행 시작.command**를 더블클릭하고 [웹 가상주행](http://127.0.0.1:8090/)을 엽니다. 기존 앱 데이터는 삭제하지 않습니다. 에뮬레이터와 웹 탭을 모두 켜두세요. 웹을 닫으면 가상 센서 전송이 멈추고 곁은 연결 대기로 돌아갑니다.

공식 Pleos 콘솔 `http://127.0.0.1:8088/`은 별도로 유지합니다. 새 가상주행은 **8090**이며 공식 콘솔의 실제 VHAL 속도와 섞지 않습니다. 실제 SDK 시험은 기존 `60도로 음성 테스트.command`를 사용합니다.

1. 연결 표시가 **곁 앱 연결됨**이면 **시동 걸고 출발**을 누릅니다.
2. ACCEL을 길게 누르거나 ↑ / W로 가속합니다. BRAKE 또는 ↓ / S / Space로 감속합니다.
3. ← / → 또는 조향 슬라이더로 차선을 바꿉니다. Q / E 또는 화살표 버튼으로 방향지시등을 켭니다.
4. 아래의 도로·주변·차 안·차량 상태를 자유롭게 바꿉니다. 차의 위치, 속도, 주변 상황과 조건 지속 시간이 함께 판정됩니다.
5. 오른쪽에서 곁의 판단과 **차량 앱에서 음성 안내 중 / 완료**, 이번 주행의 기록을 확인합니다. 캐릭터도 웹에서 바꿀 수 있습니다.

페달을 약하게 또는 강하게 밟는 차이는 아래 **페달을 밟는 힘**으로 조절합니다. 낮추면 같은 버튼을 눌러도 부드럽게 출발·감속하고, 높이면 급격하게 속도가 변합니다.

## 먼저 확인할 동작

| 조작 | 기대하는 반응 |
| --- | --- |
| 도심로에서 60을 넘겨 2초 이상 유지 | 과속 경고 음성 |
| 같은 제한에서 60 이하로 3초 유지 | 감속 격려 |
| 주행 중 운전자 벨트 해제 | 탑승자 벨트 주의 |
| 터널에서 창문 열림 유지 | 터널 창문 안내 |
| 주행 중 한 손 상태를 8초 이상 유지 | 양손 운전 안내 |
| 어린이보호구역에서 제한 30을 초과 | 보호구역 속도 주의 |
| 방향지시등 없이 차선을 바꿈 | 방향지시등 안내 |
| 앞차 간격을 좁힌 채 주행 | 차간거리 주의 |
| 졸음 상태로 주행 / 휴게 공간에서 P단 정차 | 휴식 안내 / 휴식 격려 |

한꺼번에 여러 조건이 생기면 과속 등 주의 안내가 먼저 나옵니다. 반복 음성에는 간격이 있으므로 모든 상태 변경마다 즉시 말하지는 않습니다. 해소된 상황의 대기 안내는 취소합니다. **처음부터**는 가상 차량과 코칭 타이머를 초기화하며 저장된 운전자 기록은 삭제하지 않습니다.

## 연결 구조와 범위

`웹의 차량 물리·환경 → 센서 값(초당 4회) → 곁 규칙 엔진 → Media3 파일 음성 → 웹에 재생 상태 표시`

- 입력에는 속도, 도로 제한, 거리, 창문, 벨트, 손/발, 신호·보행자·날씨 등 합성 센서 값만 들어갑니다. 판정 결과·출처·시각은 웹에서 지정할 수 없습니다.
- 앱이 받은 시각으로 실시간 조건 유지 시간을 계산합니다. 50상황 시험의 가속된 가상 시계는 사용하지 않습니다.
- 마지막 입력이 1.6초 이상 오래되면 안내를 중지하고 연결 대기로 표시합니다. 가상 기록은 WEB_SIM으로 분리합니다.
- 브라우저는 음성을 합성하거나 재생하지 않습니다. 곁 앱이 기존 네 캐릭터 파일을 재생합니다. Gleo 자동 판단으로 표시하지 않습니다.
- 이 환경의 보행자·차선·실내 인지 등은 가상 값입니다. 실제 차량에 해당 센서가 연결된 것으로 간주하지 않습니다.
- 브리지는 debug 에뮬레이터에서만 loopback에 열립니다. ADB가 Mac의 8090을 기기 내부 8765로 연결합니다. 실제 차량을 제어하지 않고, release Manifest에는 네트워크 권한을 추가하지 않았습니다.

구현 위치는 `app/src/debug/assets/web-simulator`, `WebSimulatorBridge.kt`, `WebSensorProtocol.kt`입니다. 웹 화면·센서·네이티브 음성은 같은 APK 버전으로 제공합니다.
